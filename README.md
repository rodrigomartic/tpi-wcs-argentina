# Sistema Centralizado de Gestión de Datos Biológicos y Telemetría Marina
**Organización:** WCS Argentina (Programa de Conservación Marina)
**Autor:** Rodrigo Daniel Martic

## Descripción del Proyecto
Este sistema digitaliza, almacena y visualiza de manera centralizada los registros biométricos y de geolocalización de tiburones y rayas en el Mar Argentino. 
Su objetivo es optimizar el análisis científico de la ONG WCS Argentina, eliminando la pérdida de información en papel y permitiendo el seguimiento telemétrico de las especies 
para fortalecer las políticas de conservación oceánica.

## Tecnologías Utilizadas
* **Base de Datos:** SQL / Manejo de entidades relacionales (Ejemplar, Registro, Investigador).
* **Procesamiento de Datos:** Python y R.
* **Gestión de Entorno:** Git y GitHub.
